# Todo List Application

A simple and elegant todo list application built with Flask and modern web technologies.

## Features

- Create todos with text, date, and color coding
- Color-coded tasks for better organization and priority management
- Delete tasks when completed
- Clean and modern user interface
- Responsive design
- Visual feedback with hover effects

## Technologies Used

- Backend: Python Flask
- Frontend: HTML, CSS, JavaScript
- CORS support for cross-origin requests

## Setup and Installation

1. Clone the repository:
```bash
git clone https://github.com/openhands/todo-list-app.git
cd todo-list-app
```

2. Install dependencies:
```bash
pip install flask flask-cors
```

3. Run the application:
```bash
python app.py
```

4. Open your browser and navigate to `http://localhost:53191`

## Usage

1. Add a new todo:
   - Enter the todo text
   - Select a due date
   - Choose a color (optional)
   - Click "Add Todo"

2. Delete a todo:
   - Click the "Delete" button next to the todo

3. Color coding:
   - Use different colors to indicate priority or category
   - Default color is blue
   - Colors appear as vertical bars on the left of each todo
